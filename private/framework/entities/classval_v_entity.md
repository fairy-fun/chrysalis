# Target Doctrine
## Entities

Reserved for:

real graph identities

### Examples:

* people
* places
* songs
* events
* concepts
* narratives
* subjects
* objects

These participate in:

* lineage
* graph traversal
* canonical slots
* semantic relations

## Classvals

Reserved for:

closed ontology / classification values

### Examples:

* adjudication statuses
* contradiction states
* access states
* comparators
* projection types
* expression values

These are:

* not graph entities
* not lineage participants
* not semantic actors
* not canonical fact subjects/objects

They are vocabulary atoms.

---

### What To Remove

The following doctrine becomes obsolete:

entity_type_classval

because classvals are no longer required to exist in entities.
